# V45 Premium Component System

## Scope
- Canonical component contracts: Button, Card, ProductCard, PricingCard, Badge, Avatar, Field/Input/Select/Textarea, Modal, Drawer, Tabs, Breadcrumbs, Tooltip, Pagination, EmptyState, LoadingState, ErrorState, Toast, Footer/Header.
- Interaction rule: motion communicates hierarchy, state, feedback or continuity; no decorative motion by default.
- Accessibility: visible focus, keyboard Tabs navigation, reduced-motion support, semantic roles for states/dialogs.

## QA
Run `npm run verify:premium-components` and `npm run typecheck`.
